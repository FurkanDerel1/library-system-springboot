 Library Management System - Project Task 5

This project is a Library Management System developed with Spring Boot and integrated with a MariaDB database.

 Features
- CRUD Operations: Create, Read, Update, and Delete books.
- Database Integration: Persistent data storage using MariaDB.
- Docker Support: Easy setup with Docker for consistent development environments.
- Bootstrap Design: Modern, responsive, and user-friendly interface.

 Technologies Used
- Language: Java 17
- Framework: Spring Boot 4.0.6
- Template Engine: Spring Data JPA & Hibernate
- Frontend: Thymeleaf
- Build Tool: Docker & MariaDB

 How to Run

3. Ensure all Gradle dependencies are loaded.
4. Run
